# 去 AI 味专项：首轮

基线提交：`5cc3a5e`。范围是界面和介绍文案，不改写文章，不重做已经确认的交互。

## 现状

- 个人博客，主要入口为文章、OhMyCode 项目演示、简历、关于和邮箱。
- 保留灰白底色、深绿色强调色、OhMyCode 的绿色 My、全宽首页、工牌和解密名字。
- 沿用现有 CSS Modules、GSAP 和系统字体；不加入新的界面库或字体请求。
- 按保留式改造处理：布局差异 6 / 动效 6 / 内容密度 4。项目演示本身继续承担主要动效。

## 本轮处理

| 发现 | 调整 |
| --- | --- |
| 首屏和关于重复强调“有记忆点的数字体验”等抽象理念 | 改为前端、Web 安全、OhMyCode 和既有文章主题 |
| 联系区域像营销落地页的通用邀约 | 简化标题，直接展示实际邮箱 |
| 每篇文章都附加“打开”标签，日期使用终端式等宽字 | 去掉重复标签，日期使用正常字体及等宽数字 |
| 工牌仍有权限字样、虚构编号、条码、翻面说明 | 替换为站点身份、项目和实际 GitHub 地址；保留正反面交互和原图形 |
| Multi-Agent 结尾重复泛化口号，任务卡阴影过重 | 用具体功能与交付项描述结果，减小圆角，以内描边表达当前步骤 |
| 项目结尾重复已经展示过的能力，仍有旧工作空间文案 | 用一段项目介绍配真实演示和 GitHub 入口 |
| 长文章标题被放大成宣传海报 | 减小标题字号和字重，改善换行 |
| 旧项目卡片与拖动提示的样式仍留在首页组件 | 清除不再使用的样式 |

## 保留边界

- 不修改导航文案、页面地址、锚点、文章标题或正文。
- 不修改备案信息、简历文件、站点品牌和 SEO 元数据。
- 保留用户确认的 O 转场、手机翻转、角色高亮、图标落地弹跳、逐层收纳及背景工具雨。
- 不为减少视觉装饰而删除功能性状态，例如当前角色高亮和审查结果。
- 本轮只在本地预览，不自动推送或部署。

## 复查

- TypeScript、ESLint 和差异格式检查通过。
- 桌面与手机检查首页、关于、联系方式及文章排版，手机没有横向溢出。
- 文章列表默认 5 篇，加载更多后显示全部 12 篇。
- 简历 PDF、工牌正反面资源返回 200。
- 文章图片仍可点击预览，Esc 可关闭；Multi-Agent 演示没有预览弹窗。
- 中英文介绍可切换；减少动态效果模式下，项目内容仍完整可见。
- Safari 视频兼容性仍沿用此前的调整，本轮没有 Safari 真机验证。
