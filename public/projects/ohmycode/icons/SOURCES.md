# Icon sources

MCP icons are local 96px copies of the server icons returned by the ModelScope public MCP directory. They represent extension examples, not bundled or preconfigured integrations.

Directory: https://www.modelscope.cn/mcp

Query endpoint: PUT https://www.modelscope.cn/api/v1/dolphin/mcpServers

Skill illustrations use publisher or technology logos from Simple Icons via Iconify, and the Playwright project's logo from https://playwright.dev/img/playwright-logo.svg. Simple Icons artwork is CC0; brand names and marks remain with their owners. These are visual illustrations, not unique official skill logos.

Skill sources: https://github.com/anthropics/skills and https://github.com/vercel-labs/agent-skills

Icon sources: https://github.com/simple-icons/simple-icons and https://iconify.design
